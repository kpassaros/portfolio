# Política de dados do portfólio

## Labs
Todos os Labs usam dados, pessoas, empresas e indicadores 100% fictícios.

## Cases baseados em aplicações reais
As demonstrações usam dados sintéticos e estruturas anonimizadas. Resultados reais aparecem somente de forma agregada, com contexto e sem identificadores.

## Conteúdo proibido
Não publicar credenciais, tokens, endpoints internos, nomes de clientes, dados pessoais, responsáveis, registros operacionais, CNPJs, telefones, e-mails corporativos ou bases originais.

## Identificação visual
Cada projeto deve preencher `projectType`, `dataNature` e `disclosure` em `project.json`.
