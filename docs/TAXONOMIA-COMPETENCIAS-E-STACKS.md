# Taxonomia de competências e stacks

## Competências

Capacidades aplicadas para resolver problemas: Business Intelligence, análise, modelagem, governança, automação, integração, desenvolvimento de soluções, transformação digital, gestão de projetos/requisitos e comunicação de dados.

## Linguagens, consultas e marcação

SQL, Python, DAX, M, JavaScript, HTML, CSS e Google Apps Script.

> HTML é linguagem de marcação; CSS é linguagem de estilos; DAX e M são linguagens de expressão/consulta.

## Plataformas e ferramentas

Power BI, Power Query, Excel, Google Sheets, QlikView, Looker Studio, Power Automate, Notion, Visual Studio Code, Git, GitHub, Bizagi Modeler, VTEX e TOTVS Protheus.

## Bancos e plataformas de dados

SQL Server, MySQL, Snowflake, Microsoft Fabric e Azure.

## Integração e formatos

REST APIs, Webhooks, JSON, CSV, XML, ODBC e QVD.

> JSON, CSV e XML são formatos de dados. REST é um estilo arquitetural de integração. Webhook é um mecanismo de comunicação orientado a eventos. ODBC é um padrão de conectividade. QVD é uma estrutura de armazenamento do ecossistema Qlik.

## Métodos e práticas

Modelagem dimensional, Star Schema, ETL/ELT, qualidade e governança, KPIs, storytelling, requisitos, processos, Agile/Kanban, Design Sprint, RACI/5W2H, DoR/DoD, documentação e testes.
