# Commercial Performance & Data Governance

Carga governada de metas por marca com validação, versionamento, histórico e consumo analítico.

## Problema
Metas descentralizadas e sem validação reduziam a confiabilidade do acompanhamento comercial.

## Meu papel
Construção do fluxo de captura, chave composta, validações, comparação de versões e persistência.

## Solução
Pipeline com planilha, QlikView/QVD e MySQL para classificar inclusões, atualizações e registros mantidos.

## Resultados
- 15.555 registros processados em uma carga documentada
- 61 unidades e 255 marcas no escopo agregado
- Histórico analisado superior a 229 mil linhas

## Stack
QlikView · Google Sheets · MySQL · SQL · Google Apps Script · QVD

## Dados
Empresa anônima. Demonstração fictícia; volumes agregados correspondem a evidências reais do projeto.
