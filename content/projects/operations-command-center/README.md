# Operations Command Center

Visão executiva integrada da operação de Tecnologia: sustentação, projetos, capacidade, risco e prioridades.

## Problema
Chamados, projetos e tarefas disputavam capacidade sem uma leitura consolidada para priorização.

## Meu papel
Arquitetura do modelo, definição de indicadores, experiência executiva e criação do kit para reprodução no Power BI.

## Solução
Dashboard HTML com dados sintéticos e kit Power BI contendo bases, modelo, medidas e tema.

## Resultados
- Visão Run, Improve e Change
- Capacidade, WIP, SLA, backlog e risco em uma tela
- Kit reproduzível para Power BI Desktop

## Stack
Power BI · HTML · DAX · Power Query · CSV

## Dados
Base e indicadores 100% fictícios, inspirados em desafios operacionais reais.
