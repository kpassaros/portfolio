# HTML Visual Components para Power BI

Biblioteca de componentes HTML para reunir meta, realizado, variação e contexto em uma UI compacta.

## Problema
Visuais tradicionais exigiam vários objetos para comunicar progresso, comparação e status.

## Meu papel
Concepção dos componentes, prototipação visual e preparação para uso com medidas do Power BI.

## Solução
Playground com cards reutilizáveis e documentação de integração por medidas DAX.

## Resultados
- Protótipos validados
- Componentes selecionados para o próximo deploy
- Biblioteca preparada para evolução e reutilização

## Stack
Power BI · HTML · CSS · JavaScript · DAX

## Dados
Protótipo e dados 100% fictícios. Componentes em implementação para um próximo deploy.
