# Production Performance Intelligence

Painel para acompanhar produção, rendimento, perdas, lotes, lead time e riscos operacionais.

## Problema
A operação precisava conectar volume produzido, eficiência, perdas e criticidade de lotes em uma leitura única.

## Meu papel
Análise do relatório original, reconstrução do modelo demonstrativo e definição de uma arquitetura reproduzível.

## Solução
Case recriado com dados sintéticos, dashboard HTML e kit de modelagem para Power BI.

## Resultados
- 13 perspectivas do relatório original consolidadas em uma jornada analítica
- Visões de rendimento, perdas, lead time e risco
- Base sintética pronta para estudo e reprodução

## Stack
Power BI · DAX · Power Query · CSV

## Dados
Processo inspirado em aplicação real; produtos, lotes, valores e indicadores são fictícios.
